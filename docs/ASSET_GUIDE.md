# Asset Guide

## Reference hierarchy
1. Client-supplied Ventum logo artwork = brand source of truth.
2. Client-supplied product/shop photos = source of truth for products/stock actually shown.
3. ElectraFix Figma kit = UI/UX inspiration and layout reference only.
4. Manufacturer product photography may replace weak catalogue shots only when the exact product/model is verified and usage is appropriate.

## Logo handling
Do not redesign, recolour, distort, redraw, add effects, change proportions, or reinterpret the logo. Sharpen/clean only. Keep a horizontal main lockup and a compact circular variant where needed.

## Product imagery
Client photos are authentic but inconsistent in framing/background quality. Preserve originals in `reference/client-products/`. Production-ready crops/cleanups should live separately under `public/images/products/` when created.

Do not label an external product photograph as an exact SKU unless the brand/model and visible configuration match.

## Figma inspiration
The supplied ElectraFix electrical-repair Figma UI kit is not the business identity. Translate its industrial composition, section rhythm, hierarchy, cards and responsive behavior into a product-catalogue experience. Replace repair-worker emphasis with electrical equipment/product compositions.

## Suggested reference directory
- `reference/figma/`
- `reference/brand/`
- `reference/client-products/`
- `reference/notes/`

## Production asset directory
- `public/brand/`
- `public/images/products/`
- `public/images/editorial/`

Never overwrite the original reference files when editing/sharpening assets.
