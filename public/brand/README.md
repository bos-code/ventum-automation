# Brand assets

The client-supplied Ventum logo is live here, sourced from
`project-source/assets/source-images/raw/` and reformatted to PNG only
(no redesign, recolour, or crop into the artwork itself):

- `ventum-mark.png` — circular VG mark. Used in the header/footer `Logo`
  component and as the site favicon (`app/icon.png`).
- `ventum-horizontal.png` — full mark + wordmark lockup, as supplied.
  Not currently placed anywhere in the UI (the supplied file has more
  black canvas around the content than fits a compact nav bar); available
  for a spacious placement (e.g. an About section) if useful later.

Do not redesign, recolour or distort the logo — sharpen/clean only.
